# Обработчик исключений. Конструкция try - except

В Python ошибки, возникающие во время выполнения программы, называются исключениями.

## Основная конструкция

```python
try:
    # код, который может вызвать ошибку
except ОшибкаТипа:
    # код, который выполняется при ошибке
```

## Частые типы исключений

- ZeroDivisionError — деление на ноль
- ValueError — неверное значение
- TypeError — неверный тип данных
- IndexError — выход за пределы списка
- FileNotFoundError — файл не найден

## Полная форма

```python
try:
    # код
except SomeError:
    # обработка ошибки
else:
    # выполняется, если ошибок не было
finally:
    # выполняется всегда
```

## Зачем это нужно

Обработка исключений помогает программе не падать, а корректно реагировать на ошибки.
